--------------------------------------------------------------------------
PURPOSE
--------------------------------------------------------------------------
The website and the Substack use DIFFERENT slugs for the same article.
The website slug is set in content/articles.ts. The Substack slug is chosen
during the SEO pass for search intent. This file maps one to the other so
the website's empty substackUrl fields can be filled in correctly.

--------------------------------------------------------------------------
PUBLICATION IDENTITY (decided 24 August 2026)
--------------------------------------------------------------------------
Publication name (masthead) : The Deeper Pour
Subdomain / base URL        : https://corktotable.substack.com
Author byline               : Rohan Modwel

The display name and the subdomain are deliberately different. The masthead
carries the editorial identity; the URL carries the Cork to Table brand and
matches the canonical domain. Substack keeps these as separate settings.

Reasons on record:
 - "Cork to table" does not describe the data-led nature of the writing.
 - The subdomain is effectively permanent. Changing it breaks all links, and
   the redirect-preserving change can be used only once, so it is held at
   corktotable.substack.com to match the canonical domain.
 - The publication name is free to change at any time in Settings > Basics,
   so the masthead stays a low-risk decision.
 - Collision check, 24 Aug 2026: no wine publication, podcast or brand found
   using "The Deeper Pour". Nearest neighbour is The Pour Over, a general
   news newsletter in a different category.

Tagline (working)  : Data-led wine stories from Cork to Table
About page must state that every article links to its page on corktotable.co
for the interactive visuals. That line is what connects the two names for a
reader who arrives at only one of them.

<BASE> below resolves to https://corktotable.substack.com

HOW THE WEBSITE USES THIS
--------------------------------------------------------------------------
In content/articles.ts, fill the substackUrl field on the matching entry:

  {
    slug: 'every-wine-has-its-moment',
    ...
    substackUrl: '<BASE>/p/why-wine-tastes-different-in-summer',
  },

  {
    slug: 'the-reward-for-curiosity',
    ...
    substackUrl: '<BASE>/p/does-expensive-wine-taste-better',
  },

Also in content/site.ts, substackUrl is the publication homepage, not an
article. Set it to <BASE> once live. It currently reads '' and that empty
value is what keeps Substack links hidden in the footer, on Stories & Trends,
and on About.

--------------------------------------------------------------------------
CANONICAL URL RULE (decided 18 August 2026)
--------------------------------------------------------------------------
The full article text is published in BOTH places: on the website and on
Substack. Neither is condensed. That creates duplicate content, so the
website is declared canonical and Substack points back to it.

At publish time, in Substack's post settings, set the canonical URL to the
matching website page:

  Piece 1 -> https://corktotable.co/stories-and-trends/every-wine-has-its-moment
  Piece 2 -> https://corktotable.co/stories-and-trends/the-reward-for-curiosity

Why: search credit accrues to corktotable.co, which is the owned asset and
carries the contact form, wine tourism and tasting pages. Substack still does
the distribution. Without this, Google picks one version itself and will
usually favour Substack early on, since a new domain has no authority yet.

SEQUENCING: CLEARED on 31 August 2026. The domain is corktotable.co. The .com
was already taken, so .co was registered at Cloudflare Registrar. The site is
live and both article pages were verified as resolving:
  https://corktotable.co/stories-and-trends/every-wine-has-its-moment
  https://corktotable.co/stories-and-trends/the-reward-for-curiosity

Also note: Substack does not render iframes, so the five interactive visuals
cannot run inside a Substack post. Use static images there and link out to
the website or to the GitHub Pages URLs for the interactive versions.

--------------------------------------------------------------------------
RULES
--------------------------------------------------------------------------
1. Slugs are set BEFORE publishing. Changing a slug after publication breaks
   every existing link, and Substack does not always redirect.
2. Do not sync the website slug to the Substack slug or vice versa. They are
   deliberately different: the website slug carries the editorial title, the
   Substack slug carries search intent.
3. When a new piece is added, update this file at the same time as the SEO
   pass, not at publish time.
