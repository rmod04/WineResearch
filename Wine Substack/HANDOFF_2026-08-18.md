## Standing rules, also in memory

No em dashes in prose, though en dashes are fine in ranges. No "X, not Y" antithesis constructions, no sentences ending on "the point". Quotes verbatim from the record file only, never paraphrased, with elisions marked. Sentence-case visual titles. One source footer per visual naming the data provider, never a scraping tool. Website slugs stay editorial, Substack slugs carry search intent. The website is canonical.
